# There is no "always packed" marker on an item

It was in the original design and removed before anything was built.

Nothing is unconditionally packed — the phone is, right up until the trip is
strange enough that it isn't — so the set of things on every list is a
property of the *template chosen for this trip*, not of the item. Templates
already do that job, and two mechanisms for one job is how they drift apart.

It also had no answerable seed source: the lists whose always-items would be
read from are the ones 自動保存 drops.
